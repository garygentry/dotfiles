**dotfiles** is a hybrid dotfiles manager: Go handles orchestration (CLI, config,
dependency resolution, state tracking and rollback) while shell scripts handle the actual
installation. The repository is a **generic engine** with conservative, personal-free
defaults; your identity, secrets choice, and custom profiles/modules live in an optional
**content overlay** that is deep-merged over it.
